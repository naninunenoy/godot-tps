# 動作確認スキル

godot-mcp を使ってゲームを起動し、ログを確認して動作確認を行う。

## 手順

1. **確認項目と期待する挙動を提示する**
   - 何を確認するかを箇条書きで列挙する
   - 各項目の期待する挙動を明記する
   - ユーザーの承認を待たずそのまま次のステップへ進む

2. **プロジェクトを起動する**
   - `run_project` でゲームを起動する
   - 起動直後に `get_debug_output` でログを確認する
   - エラーや警告があればそこで報告する

3. **操作が必要な場合は godot-ext を使う**
   - `godot-ext` のツール（`press_action` など）は `run_project` 後でないと使用不可
   - アクション確認が必要なら `get_actions` でアクション一覧を取得してから操作する

4. **結果を報告する**
   - 各確認項目について OK / NG を明示する
   - NG の場合は該当ログを引用して原因を示す
   - 問題があれば修正案を提示する

5. **プロジェクトを停止する**
   - 確認完了後は `stop_project` でプロジェクトを停止する

## 注意事項

- `take_screenshot` は明示的に「スクリーンショットを撮って」と指示された場合のみ使用する
- godot-mcp 経由で起動したプロセスのみ `get_debug_output` で取得できる
